# Домашнее задание к работе 6

## Условие задачи (Вариант 11)

Составить программу, которая проверяет, принадлежит ли заданная пользователем точка с координатами (x, y) заданной закрашенной (заштрихованной) области, показанной на рисунке, и выводит на экран сообщение.

Область расположена справа от оси Oy (x ≥ 0) и состоит из двух частей:
- при y ≥ 0 — часть эллипса x²/16 + y²/9 ≤ 1;
- при y < 0 — часть круга x² + y² ≤ 16.

Граничные точки входят в область.

* * *

## 1. Алгоритм и блок-схема

### Алгоритм

1. Запросить у пользователя координаты точки `x` и `y`.
2. Проверить условие принадлежности области:
   - если x ≥ 0 и y ≥ 0 и x²/16 + y²/9 ≤ 1, то точка принадлежит области;
   - если x ≥ 0 и y < 0 и x² + y² ≤ 16, то точка принадлежит области;
   - иначе точка не принадлежит области.
3. Вывести на экран сообщение о результате проверки.
4. Завершить программу.
